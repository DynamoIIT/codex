# FrostChat

A full functional real-time chatting platform built on WebSockets with a glassmorphism aesthetic.

## Features

- Live room chat (`#General` + custom rooms)
- 1:1 direct messages
- Profile creation and editing (username, bio, status, avatar hue)
- Follow/unfollow users
- Online users presence panel
- Mention pings using `@username` + highlight for mentioned messages
- Typing indicators for room and DM contexts
- Dark + light themes (dark optimized, subtle frosted glass)
- Unread DM counters
- Auto-reconnect and local session persistence

## Run

```bash
npm install
npm start
```

Open http://localhost:3000
